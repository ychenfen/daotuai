## 已做

| 环节 | 做法 | 来源 | 我们的二次优化 |
|---|---|---|---|
| 剧本 | 故事圣经（人设卡、关键道具表）→ 分集节拍 → 逐集写 | Dramatron、AI Comic Builder | 道具表加“容易被误写成的东西”，一路查到提示词 |
| 剧本 | 付费卡点按总集数定位、集末钩子三类、压/放二选一 | MYStudio、drama-creator | 卡点由代码定，集数少时自动减少卡点；同类钩子不连用 3 集 |
| 剧本 | 代码先算指标、审核直接采信，A/B/C/D 分级，C 定向改写、D 重写 | MYStudio | 指标加道具误写、易翻车写法、贴字；道具误写按场判定、人物自带物品不算 |
| 剧本 | 屏幕/短信文字不让视频模型画，后期贴字（逐行点亮） | MYStudio | `【贴字】` 一路进分镜 overlay、不进提示词、合成成字幕 |
| 剧本 | 类型节奏骨架、改编追踪表、禁用心理描写、钩子强弱 | MYStudio、scriptify、OnlyShot | 10 种类型骨架；长篇素材自动附改编追踪 |
| 剧本 | 改节拍只重写受影响的集；每次改写前存版本 | Dramatron | 版本可一键恢复；体检按文本指纹缓存 |
| 分镜 | 一卡 2~4 个子镜头、景别有变化；段时长 ≥ 台词时长 | 火宝短剧、Toonflow | 【0-3秒·近景】写法，拆卡保留景别 |
| 分镜 | 连续同景别检查、长台词切听者反应镜、每段一个主动作 | Toonflow shotCraft | 进“动作过密”提示 |
| 分镜 | 写清谁在哪、重要人/物写全名、同框 ≤2 人 | ViMax、MovieAgent | 站位图挂关键道具参考 |
| 提示词 | 只引用本镜出场人物；易翻车写法清单 | 火宝短剧、OnlyShot | 提示词卡片直接显示告警，手改也重算 |
| 出片 | 防拼图（三视图参考时写“单镜头完整画幅”） | LocalMiniDrama | 负面词同时加分屏/拼图/宫格 |

| 出片 | 多人防克隆、画外音嘴不动 | Toonflow、OnlyShot | 人数和外貌取自资产描述 |
| 出片 | 连戏快照（上一镜结束状态注入下一镜） | LocalMiniDrama | 不另花钱：质检顺带记录 |

| 平台 | 断点续跑 | huobao-drama | 视频按任务号续轮询（原本就有）；一键成片/批量生产一键续跑 |
| 成片 | 剪映草稿导出 | pyJianYingDraft | 按剪辑页时间线生成，素材路径改写到电脑目标文件夹 |

## 暂缓（原因）

| 做法 | 来源 | 为什么暂缓 |
|---|---|---|
| 口型同步 | MuseTalk 1.5（MIT，可商用）、LatentSync 1.6、InfiniteTalk | 需要 GPU（12~18GB 显存），服务器和电脑都没有；有 GPU 后接在配音之后 |
| 视频自动配音效 | HunyuanVideo-Foley | 需要 GPU（12~20GB），许可未核对 |
| 字幕 whisper 对齐 | MoneyPrinterTurbo | 我们的配音是逐句合成，时间本来就准；模型原生台词才需要，等量大再接 ASR |
| 竖屏包装模板（标题条/角标/片尾） | Pixelle-Video | 服务器缺中文字体与无头浏览器，先补字体再做 |
| 参考图按朝向挑视图 | ViMax | 需要先把三视图拆成单视图，属于资产环节改造 |
| 首尾帧关键帧驱动、四宫格分镜图 | CineGen-AI、LocalMiniDrama | 需要尾帧能力确认（万相/Seedance 支持度不一） |
| Seedance 提示词去掉绝对时间轴 | Toonflow | 和我们现在的写法相反，等 Seedance 开通后先做小样 A/B |
| 质检改布尔项 | MYStudio | 现有“分数 + 问题 + 严重度”已够用，盲区已吸收 |
